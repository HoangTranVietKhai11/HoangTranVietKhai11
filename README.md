## Career Objective
Sinh viên năm 4 chuyên ngành **Quản trị mạng** tại UMT, định hướng **System Administrator → Network Engineer → Enterprise Infrastructure Architect**.
Có nền tảng về Windows Server, Active Directory, TCP/IP và quản trị hệ thống, cùng kinh nghiệm thực tế biên soạn, chuẩn hóa tài liệu kỹ thuật khi đảm nhận vai trò Tech Lead.
Mục tiêu: vận hành, quản trị và đảm bảo tính ổn định, bảo mật cho hệ thống máy chủ và hạ tầng mạng doanh nghiệp.
